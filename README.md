# 디지털새싹 일정판 (saessak-schedule)

학교 담당자(마스터)가 동료 선생님들과 디지털새싹 수업 일정을 조율하는 도구입니다.
**마스터를 중심으로 한 1:1 공유**라, 선생님끼리는 서로의 일정을 보지 않습니다.

- 마스터: 수업을 배정하고 전체를 봅니다.
- 선생님: 자기에게 배정된 수업 + 마스터가 "모두에게 보이기"로 켠 수업 + 자기가 적은 안 되는 날만 봅니다.
  다른 선생님의 안 되는 날은 **응답에 담기지도 않습니다**(화면에서 감추는 것이 아닙니다).
- 겹침: 수업 날짜와 그 수업 담당 선생님의 안 되는 날이 같으면 양쪽 화면에 빨간 테두리로 표시됩니다.

## 환경변수 4개

| 이름 | 필수 | 설명 |
|---|---|---|
| `MASTER_CODE` | ✔ | 담당자(마스터) 로그인 코드. **숫자 4~8자리**여야 합니다 — 입장 칸이 숫자만 받기 때문에 문자가 섞이면 어떤 입력으로도 들어갈 수 없습니다. 없거나 어긋나면 기동 로그에 경고가 뜨고 `/api/health` 의 `masterCodeValid` 가 `false` 가 됩니다. |
| `COOKIE_SECRET` | ✔ | 로그인 쿠키 서명 열쇠. 없으면 임시로 만들지만 재시작마다 모두 로그아웃됩니다. |
| `DATA_DIR` | ✔(배포 시) | 자료를 둘 폴더. Railway 에서는 볼륨 경로 `/data`. 기본값은 `./data`. |
| `PORT` | | 포트. 기본 3000 (Railway 가 자동으로 넣어 줍니다). |

## 볼륨

자료는 `DATA_DIR/data.json` 한 파일입니다. **Railway 에는 반드시 볼륨을 `/data` 로 마운트하고
`DATA_DIR=/data` 를 넣어 주세요.** 볼륨 없이 배포하면 재배포할 때마다 자료가 사라집니다.

쓰기는 임시 파일 → fsync → rename 순의 원자적 쓰기이고, 직전 세대를 `data.json.bak` 으로 1벌 남깁니다.
파일이 깨져 읽지 못하면 빈 값으로 넘어가지 않고 `data.json.corrupt-YYYYMMDD` 로 보존한 뒤
`.bak` 으로 복구를 시도합니다. 그래도 안 되면 덮어쓰지 않고 로그로 알립니다.

## 공휴일

공휴일은 `lib/holidays.js` 에 넣어 두고 서버가 `/api/room` 으로 화면에 내려 줍니다.

- **2026년은 확정 자료입니다.**
- ⚠ **2027년은 확정 전 자료이니 연초에 확인이 필요합니다.** 설·추석·부처님오신날은 음력이라
  해마다 옮겨 다닙니다. 관보가 나오면 `lib/holidays.js` 의 2027년 목록만 고치면 화면까지 따라옵니다.
- ⚠ **2027년 대체공휴일은 미포함입니다** — 필요하면 학교 휴업일로 추가해 주세요.
  대체공휴일은 그해 요일에 따라 정부가 정하는데, 미리 짐작해 칠해 두면 틀렸을 때
  멀쩡한 날에 수업을 못 잡게 막는 쪽으로 잘못이 납니다.

재량휴업일·방학처럼 **우리 학교만 쉬는 날**은 담당자가 설정 화면의 '학교 휴업일' 에 넣습니다.
같은 날에 둘이 겹치면 학교 휴업일 이름이 먼저 보입니다.

## 사용법 5줄

1. 담당자가 `MASTER_CODE` 로 들어가 **설정**에서 방 이름과 선생님 명단(이름·반·휴대폰 뒷자리)을 적습니다.
2. 선생님들에게 주소와 "휴대폰 뒷자리 4자리로 들어가시면 됩니다" 만 알려 줍니다.
3. 담당자가 날짜를 눌러 **[+ 수업 배정]** 으로 수업을 넣습니다(여러 날짜를 한 번에 넣을 수 있습니다).
4. 선생님은 안 되는 날에 **[+ 이날 안 돼요]** 를 눌러 적어 둡니다. 담당자에게만 보입니다.
5. 수업과 안 되는 날이 겹치면 양쪽 화면에 빨간 표시가 뜹니다 — 담당자가 날짜를 옮기면 됩니다.

## 로컬에서 돌리기

```bash
npm install
MASTER_CODE=1234 COOKIE_SECRET=x DATA_DIR=./data node server.js
npm run seed          # 예시 자료(선생님 3명·수업 9건·안 되는 날 4건). 이미 자료가 있으면 -- --force
```

`GET /api/health` 로 자료 경로와 건수를 확인할 수 있습니다.
